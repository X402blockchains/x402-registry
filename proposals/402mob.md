## Reproduce checks without payment

With Node.js 22.13+, review the script, then run in a disposable directory:

```sh
review_dir="$(mktemp -d)"
cd "$review_dir"
npm install --ignore-scripts --no-audit --no-fund viem@2.57.14
curl --fail --silent --show-error https://evidence.contact/registry-verification.json -o registry-verification.json
curl --fail --silent --show-error https://evidence.contact/registry-verification.mjs -o registry-verification.mjs
node registry-verification.mjs registry-verification.json
```

The verifier needs no key or account. It only hashes data, verifies a historical acknowledgment and reads Base RPC. `BASE_RPC_URL` can select another trusted Base RPC. Add `--offline` to check hashes and signature without chain access.

## Buyer recovery and retention

Preserve the original request bytes/content type, idempotency key, payment proof and operation ID privately. HTTP 202 means unresolved; keep the same payment authorization and do not issue another. Replaying a historical purchase must use the original interface and bytes; if the current schema rejects the old request, use signed operation recovery instead of changing its body or paying again.

1. POST `/v1/operations/{id}/challenges` with `{"payer":"YOUR_PAYER_ADDRESS","action":"status"}`.
2. Sign the exact returned `message` using the payer's EIP-191 signer.
3. GET `/v1/operations/{id}/status` with `X-402Mob-Challenge: RETURNED_ID` and `X-402Mob-Signature: SIGNATURE`.
4. Request a new action-specific challenge for `/result` or `/evidence` as needed. Each challenge lasts **two minutes**, is **single-use**, and requires a standard **65-byte signature**. An operation ID or transaction hash alone grants no access.

Challenge issuance reveals no operation existence. Status reads do not reconcile settlement; an authorized operator or assigned coordinator can reconcile a pending payment against its transaction. Do not publish usable recovery signatures.

Default result retention is **seven days**, subject to the operation's `expiresAt`. This particular operation expired at **2026-11-03T09:09:15.771Z**. Its live result has been purged; authenticated `/result` returns 410 after expiry. Payment/hash/acknowledgment metadata does not restore deleted result bytes. The explicitly published historical fixture is separate from private live recovery and does not extend retention.

[Buyer recovery documentation](https://evidence.contact/guides/evidence-recovery.md).

No private keys, API/operator tokens, usable signed payment authorizations or private retry journals are included.
